# SQL Business Analysis

This folder contains the SQL analysis developed for the **Save for Later Feature Implementation** project.

The analysis uses a synthetic e-commerce dataset and translates the project's business and functional requirements into SQL-driven business questions, KPIs, insights, and recommendations.

## 📁 Folder Contents

### Dataset
Contains the synthetic datasets used for the analysis:

- `Customers`
- `Orders`
- `Products`
- `Save_For_Later`

The datasets contain customer, order, product, and Save for Later activity data.

### Database
Contains the SQL scripts used to create and work with the database schema.

### Analysis
Contains the complete SQL Business Analysis, including:

- Business questions and objectives
- SQL queries
- Query results
- Key KPIs
- Business insights
- Business recommendations
- Business value

## 📊 Analysis Areas

The SQL analysis covers:

- **Customer & Geographic Analysis**
- **Product & Category Performance**
- **Save for Later Engagement & Conversion**
- **Time-Based Analysis**
- **Advanced SQL Analysis**

The analysis also demonstrates SQL techniques including:

- Aggregations
- `GROUP BY` and `ORDER BY`
- `INNER JOIN`
- `CASE` expressions
- Subqueries
- Correlated subqueries
- Common Table Expressions (CTEs)
- Window functions
- `DENSE_RANK()`
- Date-based analysis

## 📄 SQL Business Analysis Report

The complete analysis is documented in:

**`SQL Business Analysis Report.pdf`**

The report is structured as a decision-support document rather than a collection of standalone queries. Each business question connects the SQL analysis to KPIs, business insights, recommendations, and business value.

## 🗃️ Data Source

All datasets used in this analysis are **synthetically generated for portfolio purposes** and do not represent data from a live production system.

## 🛠️ Tools

- **Microsoft SQL Server**
- **T-SQL**

## 🎯 Purpose

The purpose of this analysis is to demonstrate how SQL can be used to move from raw business data to actionable business insights and recommendations.
